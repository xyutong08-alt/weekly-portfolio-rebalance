# 收录与回复规则

来源：用户的每周调仓SOP及2026-11-20本轮操作确认。用户新指示优先，不修改历史周。

- 排除机构名包含：中欧（含中欧财富）、华宝、盈米基金（含且慢）、国联证券、国投证券、山西证券。**判断投顾机构，不按持仓基金品牌排除组合**。
- 记录名称（机构）、策略基准、日期、有效理由、全部基金前后权重及页面操作标签，不写分析。
- `bench`：给了用原文；明确没有用null（不显示基准行）；还没给或页面未找到用空字符串（待补充）。不要把“没找到”视作明确没有。
- 通用理由如“组合调仓”“动态优化再平衡”“优化持仓”“资产配置结构优化”“根据最近的市场情况，查理对组合进行了资产配置调整”等不写。具体投资理由照抄顶部及ID下灰字，不润色、不纠正文中观点。
- 多期系列只保留一期并去期数，如目标盈、省心投步步盈、获得感ETF目标盈、安心小火车。仅有“目标盈”字样不意味着不同策略都是同一系列，应按名称和持仓证据判断。
- 同组合同日期（本期已有）始终不重复加；上期已有通常不加，但常规周起始周五交由用户核对后，用户明确点名要求补入本期的条目可跨期收录，仅对该批准批次生效；异名/异ID但基金前后权重相同，先问用户。零→零的基金可因页面差异消失，比较时忽略这些行，但仍保存源页面记录。权重仅近似时不要判定完全重复。
- 已停止组合照常收录，status保存“已停止”；周末提醒一次。
- 权重相同而页面标签为减仓/加仓时，保留页面标签（基金数组第五项），提醒矛盾，不擅自纠正。
- “分类缺失”是合法独立资产组；分类缺失不是基金缺失。不要自动补差额到现金，也不要把权重归一化至100%。
- 回复只用中文。新增后只报编号、名称机构及日期。只在跳过、重复待决定、缺基准/日期、基金可能缺失、名称不确定、标签矛盾时多说一句。不复述基金明细、不报“合计对得上”、不讲实现步骤。
