# 周报模板

把已交付、可用于本项目的历史周报副本放在此目录。文件名写明覆盖日期。有多份时，优先参考用户点名的版本，其次参考日期最近、用途相同的一份。没有历史原件时，如果目录里有本机的 `周报版式示例.docx`，可参考其版式。

生成新周报前查看标题、日期范围、组合编号、基准与理由的顺序，以及基金表的列和资产分组。用本期已核对的数据填充。示例使用虚构数据，仅用于版式参考。跨期去重和起始周五核对使用工作目录中与上期对应的实际记录。

聊天汇报可沿用这一顺序。

> 已整理 MM-DD 至 MM-DD 的调仓，本次新增 N 个，累计 N 个。附上 Word。起始周五有 N 个策略待核对。

最后一句按实际情况加上。用户要求总结时，再根据本期记录说明主要机构和变动方向。
